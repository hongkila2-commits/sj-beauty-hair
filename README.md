# SJ BEAUTY HAIR 공식 홈페이지

대전 미용실 프랜차이즈 SJ뷰티헤어의 공식 홈페이지입니다.
브랜드 소개 · 5개 지점 안내 · 헤어칼럼 · 영상 갤러리 · 문의로 구성됩니다.

---

## 글 올리는 방법 — 세 가지 중 편한 것으로

어느 방법으로 올리든 **같은 파일**이 고쳐지므로 내용이 갈라지지 않습니다.

### 방법 1. 웹 관리자 화면 (가장 쉬움, 직원용)

1. 홈페이지 주소 뒤에 `/admin` 을 붙여 접속합니다.
2. **Login with GitHub** 를 누르고 GitHub 계정으로 로그인합니다.
3. 왼쪽에서 **헤어칼럼** 또는 **영상** 을 고르고 **New** 를 누릅니다.
4. 제목·본문·사진을 채우고 오른쪽 위 **Publish** 를 누릅니다.
5. 1~2분 뒤 홈페이지에 자동으로 나타납니다.

> 작성 중인 글은 **작성 중** 항목에 체크해 두세요. 체크된 글은 홈페이지에 보이지 않습니다.

#### 로그인이 안 될 때

**Login with GitHub** 를 누르면 작은 창이 뜹니다. 그 창이 뭐라고 하는지가 단서입니다.

| 창에 보이는 글 | 뜻 | 할 일 |
|---|---|---|
| 로그인되었습니다 → 창이 닫힘 | 정상 | — |
| 빨간 글씨로 **사유** 가 뜨고 창이 안 닫힘 | 로그인 실패 | 그 문구를 그대로 알려 주세요 |
| **관리자 화면이 응답하지 않습니다** | 창은 됐는데 관리자 화면이 못 받음 | 창을 닫고 `/admin` 을 새로고침한 뒤 다시 |
| **이 주소는 직접 여는 곳이 아닙니다** | `/api/auth` 주소를 직접 입력함 | `/admin` 으로 들어가 로그인 버튼을 누르세요 |
| GitHub 화면에 **redirect_uri_mismatch** | OAuth App 설정이 어긋남 | 아래를 확인하세요 |

실패한 창은 **일부러 닫지 않습니다.** 사유를 읽으실 수 있어야 하기 때문입니다.

**가장 흔한 원인은 GitHub 쪽 주소 설정입니다.** 도메인을 바꾸면 여기도 같이 바꿔야 합니다.

1. GitHub → 우측 상단 프로필 → **Settings**
2. 맨 아래 **Developer settings** → **OAuth Apps** → 해당 앱
3. **Authorization callback URL** 이 아래와 정확히 같은지 확인

   ```
   https://sjbthair.com/api/callback
   ```

4. 다르면 고치고 **Update application** 을 누릅니다.

> 쿠키를 막아두면 로그인이 안 됩니다. 시크릿 모드나 쿠키 차단 확장을 끄고 시도해 보세요.

> `sj-beauty-hair.vercel.app/admin` 에서도 로그인됩니다. 로그인 창만 대표 도메인을
> 거칠 뿐, 글은 어느 쪽에서든 올리실 수 있습니다.

### 방법 2. Obsidian (개인 집필용)

처음 한 번만 설정하면 됩니다.

1. 이 저장소를 컴퓨터로 내려받습니다.
2. Obsidian 을 열고 **Open folder as vault** 로 `content` 폴더를 지정합니다.
3. 커뮤니티 플러그인에서 **Obsidian Git** 을 설치합니다.
4. 글을 쓰고 저장한 뒤, Obsidian Git 의 **Commit and push** 를 누릅니다.

글 맨 위에는 아래 형식을 그대로 넣어주세요. 이 부분이 제목·날짜·분류가 됩니다.

```markdown
---
title: 글 제목
date: 2026-09-20
category: 헤어칼럼      # 헤어칼럼 / 스타일 / 공지 중 하나
summary: 목록에 보일 한 줄 요약
author: SJ뷰티헤어 둔산본점
draft: false            # true 로 두면 홈페이지에 안 보입니다
---

여기부터 본문입니다.
```

**사진**은 글에 그냥 붙여넣으면 됩니다. `content/posts/attachments/` 에 저장되고,
홈페이지에서는 자동으로 압축돼 표시됩니다. (설정이 이미 되어 있습니다)

### 방법 3. Claude 에게 맡기기

"이번 주 헤어칼럼 써서 올려줘" 처럼 부탁하면 초안 작성부터 게시까지 대신 합니다.

## 정보를 바꾸고 싶을 때

### 관리자 화면에서 바꾸는 것 (코드 몰라도 됩니다)

`/admin` 에서 아래를 전부 직접 고치실 수 있습니다. 저장하면 1~2분 뒤 홈페이지에 반영됩니다.

| 메뉴 | 바꿀 수 있는 것 |
|---|---|
| **헤어칼럼** | 글 작성·수정·삭제 |
| **영상** | 유튜브 영상 등록. 대표 이미지를 올리면 그 사진이 쓰이고, 누르면 유튜브로 이동합니다 |
| **이벤트·프로모션** | 할인·혜택 안내. 카드뉴스를 한 장씩 추가·삭제·순서변경 |
| 사이트 설정 → **연락처 · 영업시간** | 브랜드 카피, 소개글, 이메일, 인스타그램, 대표 전화·예약 주소, 영업시간, **검색엔진 인증코드** |
| 사이트 설정 → **지점별 정보** | 지점별 전화·예약·플레이스·**블로그**·지도 주소, **가격표 On/Off 와 가격 항목** |
| 사이트 설정 → **메인 화면** | 히어로 문구·사진, 숫자 소개, **대표 시술 4종**(이름·사진·설명·링크), 각 섹션 제목 |
| 사이트 설정 → **페이지 문구** | 지점안내·헤어칼럼·영상·문의·채용 페이지 제목과 설명, 회사소개 본문, **회사 개요표** |
| 사이트 설정 → **띠배너 · 팝업** | 상단 띠배너 문구·링크, 팝업 제목·내용·사진·버튼 (각각 켜고 끌 수 있음) |

**예약 버튼은 넣은 값에 따라 자동으로 바뀝니다.**

| 넣은 값 | 버튼 |
|---|---|
| 네이버 예약 주소 | `네이버 예약` |
| 플레이스 주소만 | `네이버 예약·문의` |
| 전화번호만 | `전화 예약 042-…` |
| 아무것도 없음 | `인스타그램 DM 문의` |

지금은 5개 지점 모두 **플레이스 주소**가 들어가 있어 `네이버 예약·문의` 로 연결됩니다.
네이버 **예약 전용 주소**를 받으시면 지점별 정보 → 해당 지점 → **네이버 예약 주소** 칸에
넣어주세요. 그쪽이 우선 적용되고 버튼 이름이 `네이버 예약` 으로 바뀝니다.

### 검색엔진에 홈페이지 등록하기

네이버·구글에서 검색되게 하려면 "이 사이트가 내 것"임을 한 번 증명해야 합니다.
**코드를 고칠 필요 없이** 관리자 화면에서 끝납니다.

**네이버**

1. [searchadvisor.naver.com](https://searchadvisor.naver.com) 접속 → 네이버 로그인
2. **웹마스터도구** → **사이트 등록** → `https://sjbthair.com` 입력
3. 소유확인 방법에서 **HTML 태그** 선택
4. 화면에 나오는 `<meta name="naver-site-verification" content="여기값" />` 에서
   **`content=` 안의 값만** 복사
5. `/admin` → 사이트 설정 → **연락처 · 영업시간** → **네이버 사이트 인증코드** 에 붙여넣고 저장
6. **2분쯤 기다렸다가** 네이버 화면에서 **소유확인** 을 누릅니다
   (저장한 내용이 홈페이지에 반영되는 데 시간이 걸립니다)
7. 확인되면 **요청 → 사이트맵 제출** 에 `sitemap-index.xml` 을 넣습니다

**구글**

1. [search.google.com/search-console](https://search.google.com/search-console) 접속
2. **속성 추가** → **URL 접두어** → `https://sjbthair.com` 입력
3. 소유권 확인에서 **HTML 태그** 선택 → `content=` 안의 값만 복사
4. `/admin` → 연락처 · 영업시간 → **구글 사이트 인증코드** 에 붙여넣고 저장
5. 2분쯤 뒤 **확인** 을 누릅니다
6. 왼쪽 **Sitemaps** 에서 `sitemap-index.xml` 을 제출합니다

> 인증코드를 비워두면 관련 태그가 **아예 출력되지 않습니다.** 넣기 전까지는
> 홈페이지에 아무 영향이 없으니 안심하고 두셔도 됩니다.

> 검색 결과에 실제로 나타나기까지는 등록 후 **며칠에서 몇 주**가 걸립니다.
> 등록했는데 바로 안 나온다고 해서 잘못된 것이 아닙니다.

**가격표**는 지점마다 `가격표 보이기` 를 끄면 그 지점 페이지에서 통째로 사라집니다.

### 사진은 그냥 올리시면 됩니다

**휴대폰으로 찍은 사진을 크기 조절 없이 그대로 올리셔도 됩니다.** 배포할 때
자동으로 가로 1600px 이하로 줄여서 내보냅니다. 원본은 저장소에 그대로 남아
있어서 인쇄물 등에 필요하면 다시 꺼내 쓸 수 있습니다.

| | |
|---|---|
| 올리신 사진 | 4MB (4000×3000) |
| 방문자에게 전송 | 약 250KB (1600×1200) |

SVG·GIF 는 손대지 않습니다(움직임이 사라지거나 망가지기 때문). 사진이 아닌
파일이 섞여 있어도 배포는 정상 진행되고, 빌드 기록에 경고만 남습니다.

> **빈 칸은 그대로 두셔도 됩니다.** 전화번호가 비어 있으면 전화 버튼이,
> 네이버 예약 주소가 비어 있으면 예약 버튼이 **자동으로 숨겨집니다.**
> 값을 넣는 순간 버튼이 나타납니다.

### 코드를 고쳐야 하는 것

거의 바뀌지 않는 값들이라 `src/config.ts` 에 있습니다.

| 바꾸고 싶은 것 | 고칠 곳 |
|---|---|
| 지점 주소·오픈일·사진 | `BRANCH_BASE` |
| 브랜드 이름(SJ뷰티헤어) | `BRAND` |
| 섹션 번호 (01~08) | 각 페이지 `.astro` 파일 |
| 상단 메뉴 구성 | `NAV` |
| 교육과정·근무환경 내용 | `CURRICULUM`, `WORKPLACE` |
| 네이버·구글 검색 등록 인증 코드 | `VERIFICATION` |

> 지점의 **주소·사진 같은 구조 정보를 관리자 화면에 두지 않은 이유**가 있습니다.
> 관리자 화면(Decap CMS)은 **양식에 없는 항목을 저장할 때 지워버리기** 때문에,
> 실수로 지점 주소나 사진 경로가 사라지는 사고를 막으려고 코드에 남겨두었습니다.

### 자동 점검 (매주 일요일 새벽 1시)

GitHub 이 알아서 검사합니다. **문제가 없으면 아무 연락도 가지 않습니다.**

| 검사 | 내용 |
|---|---|
| 보안 취약점 | 쓰고 있는 부품에 알려진 취약점이 생겼는지 |
| 타입 검사 | 코드에 모순이 생겼는지 |

문제가 생기면 GitHub 이슈가 열리고 가입 메일로 알림이 옵니다. 이미 열린 점검
이슈가 있으면 새로 만들지 않고 댓글만 덧붙여, 이슈가 쌓이지 않습니다.

직접 돌려보실 수도 있습니다.

```bash
npm run check
```

즉시 실행하려면 GitHub 저장소 → **Actions** 탭 → **주간 점검** → **Run workflow**.

### 점검 안내 화면

매주 **일요일 새벽 1시~2시**에 방문자에게 점검 안내 화면이 표시됩니다.
`/admin` → **사이트 설정 → 점검 안내** 에서 요일·시간·문구를 바꾸거나 끌 수 있습니다.

- **점검 중에도 원장님은 보실 수 있습니다** — 주소 뒤에 `?preview=1` 을 붙이세요.
  예: `https://sjbthair.com/?preview=1`
- 손님은 점검 중에도 예약·전화·인스타그램 DM 버튼을 쓸 수 있습니다.
- 네이버·구글 검색 로봇에게는 보이지 않습니다 (검색 노출을 지키기 위함).
- **급하게 점검이 필요할 때**도 쓸 수 있습니다. 시작·종료 시각을 지금 시각으로
  바꿔 저장하면 바로 적용됩니다.

> 참고: 이것은 **안내 화면**이지 완전한 차단이 아닙니다. 브라우저 설정을
> 만지면 내용을 볼 수 있습니다. 대신 검색 노출에 전혀 해가 없습니다.

### 도메인 바꾸는 법

**`src/site.mjs` 의 `url` 한 줄만 고치면 됩니다.** 대표주소·사이트맵·RSS·카카오톡
공유 이미지·관리자 화면 설정까지 전부 여기서 나옵니다.

```js
export const SITE = {
  url: 'https://sjbthair.com',   // ← 여기만
  repo: 'hongkila2-commits/sj-beauty-hair',
};
```

고친 뒤 **반드시 함께 해야 할 것 두 가지**가 있습니다.

1. **Vercel** → Settings → Domains 에 새 도메인 추가
2. **GitHub OAuth App** → Authorization callback URL 을 `https://<새도메인>/api/callback` 로 변경
   — 이걸 빠뜨리면 `/admin` 로그인이 `redirect_uri_mismatch` 오류로 막힙니다

> 관리자 화면 설정(`public/admin/config.yml`)에는 주소 대신 `__SITE_URL__` 이
> 적혀 있습니다. 빌드할 때 자동으로 채워지므로 **이 파일은 손대지 마세요.**
> 치환에 실패하면 빌드가 멈추고 어느 파일인지 알려줍니다.

### 도메인이 안 열릴 때

```bash
npm run domain
```

지금 어느 단계까지 됐는지와 **다음에 뭘 해야 하는지**를 알려줍니다.
DNS 반영은 몇 시간에서 하루까지 걸리므로, 기다리는 동안 이걸로 확인하세요.

```
도메인 점검 — sjbthair.com

  등록        정상
  네임서버    Cloudflare (paislee.ns.cloudflare.com 외 1개)
  A 레코드    없음
  www         도메인 없음
  이전 주소   살아 있음

→ 다음 할 일: 네임서버가 아직 Cloudflare 입니다.
   ...
```

> **네임서버가 중요합니다.** 도메인은 "네임서버로 지정된 곳"이 답을 합니다.
> 가비아에서 DNS 를 설정해도 네임서버가 다른 곳을 가리키면 아무 효과가 없습니다.

### 구조

```
content/          글 원본 (Obsidian 보관함으로 여는 폴더)
  posts/          헤어칼럼 .md
    attachments/  글에 붙인 사진
  videos/         영상 정보 .md
src/
  config.ts       지점·연락처 등 모든 데이터
  pages/          페이지
  components/     공통 조각
public/
  admin/          웹 관리자 화면 설정
  uploads/        관리자 화면으로 올린 사진
api/              관리자 로그인 처리 (Vercel 서버 함수)
```

### 배포

`main` 브랜치에 push 하면 Vercel 이 자동으로 빌드·배포합니다.

관리자 화면 로그인을 위해 Vercel 프로젝트에 아래 환경변수가 필요합니다.

| 이름 | 값 |
|---|---|
| `OAUTH_CLIENT_ID` | GitHub OAuth App 의 Client ID |
| `OAUTH_CLIENT_SECRET` | GitHub OAuth App 의 Client Secret |

GitHub OAuth App 의 **Authorization callback URL** 은 `https://<배포주소>/api/callback` 으로 설정합니다.
